# Olist-Project
# Brazilian E-Commerce Sales Analysis | PostgreSQL & Power BI

## 📌 Project Overview

This project analyzes Brazilian e-commerce data from the Olist dataset using **PostgreSQL and Power BI** to explore sales performance, customer behavior, product category performance, and delivery operations.

The objective is to transform raw e-commerce data into meaningful business insights through SQL-based data analysis, KPI tracking, and interactive Power BI dashboards.

The project includes four dashboard pages covering executive sales performance, sales trends, product and category insights, and customer and geographic analysis.

## 🎯 Business Objectives

* Analyze revenue, order volume, and customer performance.
* Track key performance indicators (KPIs) to evaluate business performance.
* Identify high-performing product categories.
* Understand sales trends and year-over-year revenue changes.
* Analyze customer distribution across Brazilian states.
* Evaluate delivery performance and customer review ratings.
* Present actionable insights through interactive dashboards.

## 🛠️ Tools & Technologies

* **PostgreSQL** — Data storage, SQL queries, and data analysis.
* **Power BI** — Interactive dashboards and data visualization.
* **DAX** — Measures and KPI calculations.
* **Power Query** — Data preparation and transformation.
* **GitHub** — Project documentation and version control.

## 🗄️ Data & SQL Analysis

The project uses the Brazilian E-Commerce Public Dataset by Olist, which contains information about e-commerce orders, customers, products, sellers, payments, reviews, and geographic locations.

PostgreSQL was used to work with the dataset and prepare data for analysis. The analysis focuses on business questions related to sales, customers, products, payments, delivery, and reviews.

**Key analytical areas include:**

* Revenue and order analysis
* Customer analysis
* Product category performance
* Payment analysis
* Delivery performance
* Customer satisfaction

## 📈 Key Performance Indicators

The dashboard includes metrics such as:

| KPI                    | Purpose                                 |
| ---------------------- | --------------------------------------- |
| Revenue                | Measures sales performance              |
| Total Orders           | Tracks order volume                     |
| Total Customers        | Measures customer reach                 |
| Average Order Value    | Evaluates average revenue per order     |
| Average Review Score   | Indicates customer feedback             |
| On-Time Delivery %     | Measures delivery performance           |
| Year-over-Year Growth  | Compares revenue with the previous year |
| Rolling 30-Day Revenue | Tracks recent revenue performance       |

*Note: KPI definitions and values depend on the implemented calculations and available data.*
